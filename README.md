# Compressão de Imagens

Este é um aplicativo web projetado para compactar imagens, construído com React e Vite. Ele oferece uma interface amigável para reduzir eficientemente o tamanho dos arquivos de imagem, mantendo uma qualidade razoável.

## Funcionalidades

-   **Compactação de Imagens:** Otimize imagens para reduzir o tamanho do arquivo.
-   **Interface Moderna:** Construído com React e estilizado usando Tailwind CSS para uma experiência de usuário responsiva e moderna.
-   **Roteamento:** Utiliza React Router DOM para navegação contínua.
-   **Integração com API:** Aproveita o Axios para lidar com requisições HTTP, provavelmente para processamento ou upload de imagens.
-   **Iconografia:** Incorpora React Icons para um rico conjunto de ícones vetoriais.

## Começando

Siga estas instruções para configurar o projeto localmente.

### Pré-requisitos

Certifique-se de ter o Node.js e o npm (ou yarn) instalados em sua máquina.

-   Node.js (versão LTS recomendada)
-   npm (vem com o Node.js) ou Yarn

### Instalação

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/seu-usuario/compress-image.git
    cd compress-image
    ```
    (Observação: Substitua `https://github.com/seu-usuario/compress-image.git` pela URL real do repositório, caso esteja hospedado.)

2.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```

### Scripts Disponíveis

No diretório do projeto, você pode executar:

-   **`npm run dev`**
    Executa o aplicativo em modo de desenvolvimento.
    Abra [http://localhost:5173](http://localhost:5173) para visualizá-lo em seu navegador.
    A página será recarregada se você fizer edições. Você também verá quaisquer erros de lint no console.

-   **`npm run build`**
    Compila o aplicativo para produção na pasta `dist`.
    Ele agrupa corretamente o React em modo de produção e otimiza a compilação para o melhor desempenho.
    A compilação é minificada e os nomes dos arquivos incluem os hashes.
    Seu aplicativo está pronto para ser implantado!

-   **`npm run lint`**
    Verifica os arquivos do projeto em busca de problemas de qualidade e estilo de código.

-   **`npm run preview`**
    Serve a pasta `dist` localmente após uma compilação, permitindo que você visualize a compilação de produção.
